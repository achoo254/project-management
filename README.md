# Báo Cáo Tình Hình Các Dự Án & Phân Bổ Nhân Sự

## I. Thông tin dự án

| Tên Dự Án      | Mô Tả                                                                                       | Tình Trạng Hiện Tại                                                                                  |
|----------------|----------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------|
| **OneMail**    | Nền tảng cung cấp email doanh nghiệp theo tên miền riêng                                     | Hệ thống đã hoạt động ổn định, hoàn tất tích hợp các chức năng liên kết với Drive                    |
| **Drive**      | Không gian lưu trữ, chia sẻ file, quản lý dữ liệu theo tên miền                              | Đã hoàn thiện, đang theo dõi vận hành và tiếp tục bổ sung các chức năng chính như: nén, giải nén, xử lý file lớn |
| **Server Tools** | Hệ thống quản lý server, terminal, file và tài nguyên VPS                                  | Đang trong giai đoạn thu thập yêu cầu và xây dựng tài liệu trước khi triển khai tính năng chính      |
| **Portal**     | Nền tảng điều phối và quản trị tập trung các dịch vụ, người dùng, gói dịch vụ               | Đã đưa vào vận hành thực tế, tiếp tục phát triển thêm tính năng theo nhu cầu phát sinh              |

---

## II. Phân bổ nhân sự theo dự án

| Họ và Tên               | Dự án phụ trách                                                                 |
|-------------------------|----------------------------------------------------------------------------------|
| **Bùi Văn Hổ**          | Server Tools (Frontend)                                                         |
| **Trịnh Quốc Hoàn Đạt** | Server Tools (Backend)                                                          |
| **Nguyễn Huy Hoàng**    | Workspace (Backend – dự án Drive)                                               |
| **Nguyễn Đăng Đức**     | Workspace (Frontend – dự án Drive)                                              |
| **Đinh Tiến Chương**    | Portal (Frontend + Backend)<br>**Backup:** Bùi Văn Hổ, Nguyễn Huy Hoàng, Nguyễn Đăng Đức |
