### 📝 Nội dung chính và hướng xử lý

| Nội dung đề xuất | Mục đích | Hướng xử lý |
|------------------|----------|--------------|
| Xem lịch sử file đính kèm trong chuỗi mail | Hiển thị toàn bộ file đính kèm như Outlook | **Reject** – cần khảo sát thêm |
| Hiển thị file đính kèm trực tiếp trên mail | Cải thiện trải nghiệm hiển thị file đính kèm | **Cancel** – hệ thống không hỗ trợ, chỉ hiển thị biểu tượng |
| Tích hợp API với n8n, Google Sheet, Zapier | Kết nối dữ liệu email cho automation | **Reject** – chưa rõ tập khách hàng |
| Avatar riêng cho từng tài khoản | Cá nhân hóa tài khoản | **Khảo sát thêm** – thống kê nhu cầu dùng nội bộ / gửi ra ngoài |
| Gửi thêm email báo lỗi tiếng Việt | Cải thiện thông tin phản hồi lỗi gửi mail | **Cancel** – giữ mặc định tiếng Anh theo chuẩn hệ thống |
| Tạo email bằng giọng nói | Tăng tiện ích nhập nội dung email | **Pending** – chờ AI Speed to Text từ CEO |
| Dung lượng mail bất thường (1GB đã đầy) | Kiểm tra dung lượng thực tế | **Task kỹ thuật check lại hệ thống** |
| Email vào spam | Kiểm tra nguyên nhân hệ thống | **Liên quan IP** – xử lý bởi bộ phận kỹ thuật |
| Gửi/nhận mail chậm, bị block bởi Microsoft Mail | Cải thiện tốc độ queue mail | **Xử lý queue mail** – bộ phận kỹ thuật kiểm tra |
| Notify khách hàng dùng Outlook | Tiếp cận nhóm khách hàng Outlook cũ | **Pending** – tìm giải pháp thu thập dữ liệu |
| Hướng dẫn sử dụng email cũ | Cập nhật tài liệu theo giao diện mới | **Cập nhật lại hướng dẫn** – thay thế nội dung /mya |
| Đề xuất app mail riêng như Gmail | Tăng trải nghiệm người dùng mobile | **Reject** – dùng web + PWA (logo mặc định) |
